13. Terminology Glossary

Comprehensive reference glossary of machine learning and neural network terms.

Machine Learning

  • Artificial Intelligence (AI): Computer systems capable of completing tasks that typically require human intelligence.
  • Machine Learning (ML): Learning predictive models from data.
  • Deep Learning (DL): Learning neural network models with two or more hidden layers.
  • Supervised Learning: Learning mappings from input features to target values using labeled examples.
  • Unsupervised Learning: Extracting structure or relationships among unlabeled data examples (e.g., clustering).
  • Reinforcement Learning (RL): Learning policy agents to maximize environmental rewards.
  • Classification: Predicting discrete categorical class labels.
  • Regression: Predicting continuous numeric output values.

Neural Network Terms

  • Neural Network (NN): Computational model composed of interconnected layers of artificial neurons.
  • Neuron (Node): Unit performing linear summation followed by a non-linear activation function.
  • Activation Function: Non-linear transformation function (Sigmoid, Tanh, ReLU, Leaky ReLU).
  • Forward Propagation: Process of computing model outputs from inputs.
  • Backpropagation: Efficient application of calculus chain-rule to compute gradients.

Activation Functions

  • Sigmoid: Squashes real values into $[0, 1]$.

  • Hyperbolic Tangent (Tanh): Squashes real values into $[-1, 1]$.

  • ReLU: Rectified Linear Unit ($f(x) = \max(0, x)$).

  • Leaky ReLU: Non-zero gradient for negative inputs.
