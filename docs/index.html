Welcome to PyMatch

PyMatch (match) is an educational neural network library and interactive web platform designed for learning autograd, C-extensions, SIMD vectorization, and GPU compute shaders.

This interactive guide runs 100% client-side in your browser via WebAssembly (Pyodide). Learn how fundamental neural network components work, inspect the underlying mathematical formulations, and execute real Python code live in your browser.

Mathematical Formulations

Autograd Function Example

Consider evaluating a scalar function and its gradients:

\[ f(x, y) = x^2 y + 4x \]

Evaluated at $x = 3.0$ and $y = -2.0$:

\[ f(3, -2) = (3.0)^2 (-2.0) + 4.0(3.0) = -18.0 + 12.0 = -6.0 \]

The partial derivatives are computed via automatic differentiation:

\[ \frac{\partial f}{\partial x} = 2xy + 4 \implies \frac{\partial f}{\partial x}(3, -2) = 2(3.0)(-2.0) + 4.0 = -8.0 \] \[ \frac{\partial f}{\partial y} = x^2 \implies \frac{\partial f}{\partial y}(3, -2) = (3.0)^2 = 9.0 \]
